# Counter App

A simple counter application built with React and Redux Toolkit. This project helped me understand how state management works in React using Redux.

## Features

* Increment the counter
* Decrement the counter
* Reset the counter
* Manage counter state using Redux Toolkit
* Responsive UI with Tailwind CSS

## Technologies Used

* React
* Redux Toolkit
* React Redux
* Tailwind CSS
* Vite

## Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/abdnasir718-lab/Counter.git
```

### 2. Go to the project folder

```bash
cd Counter
```

### 3. Install dependencies

```bash
npm install
```

### 4. Run the development server

```bash
npm run dev
```

The app will be available at the local URL provided by Vite.

## What I Learned

While building this project, I practiced using Redux Toolkit to manage application state and learned how actions, reducers, and the Redux store work together in a React application.
